One campaign-history row. Type sets the left rule colour and the icon; `**bold**` in the content becomes mono emphasis. The old emoji prefixes are replaced by Phosphor glyphs.

```jsx
<LogEntry type="DICE" timestamp="20:56:01" content="掷骰 [2d6+4] 结果: **13** (2d6: [3 + 6] = 9)" />
<LogEntry type="COMBAT" timestamp="20:58:12" content="哥布林斥候 x3 受到 **8** 点物理伤害" />
```
