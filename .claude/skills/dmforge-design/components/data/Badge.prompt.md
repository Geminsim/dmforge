Small status label: character conditions, item categories, character type, sync state.

```jsx
<Badge tone="madder" icon="skull">中毒</Badge>
<Badge tone="woad" size="sm">PC</Badge>
<Badge tone="ochre" variant="outline" mono>2d6 穿刺</Badge>
<Badge tone="verdigris" onRemove={clear}>祝福</Badge>
```

Stick to the pigment semantics — a monster badge is never verdigris.
