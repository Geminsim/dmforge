One roll: formula, total, breakdown. Use `emphasis` for the most recent roll and plain for history rows.

```jsx
<RollResult emphasis formula="2d20kh1+5" total={24} detail="[7, 18 → Keep High: 18] (Mod: 18+5)" time="20:56:01" />
```

Everything numeric is mono. The total is the only accent-coloured number in the panel.
