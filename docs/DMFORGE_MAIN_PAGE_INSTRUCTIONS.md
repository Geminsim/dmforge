# DMForge 主页面完整使用指南

本指南对应当前 DMForge 主页面、玩家展示端与直播展示端。它说明界面中已经可用的功能、推荐操作顺序、数据影响范围和容易混淆的规则。

> 适用版本：当前仓库版本。界面后续变更时，应同步修改本文中对应的按钮名称和规则说明。

## 1. 启动、模式与战役选择

### 1.1 推荐打开方式

Windows 用户优先双击项目根目录的 `run.bat`。便携版用户双击 `DMForge.exe`。

应用只有一个启动入口，默认尝试启用局域网同步：

- 同步服务可用且令牌正确时，进入局域网模式。
- 服务不可用、连接中断或令牌无效时，自动降级为单机模式，本地存档仍可继续使用。
- 网络恢复后，应用会继续尝试重新连接。
- 如需明确关闭所有同步请求，可点击页面右上角的同步状态，或在“系统设置”中关闭“启用局域网实时同步”。

右下状态栏的 `LAN` 会显示“单机模式”“已连接”或“重试中”；页面右上角也会显示“局域网同步中”“自动单机使用”“同步已关闭”或“同步冲突待处理”。

### 1.2 战役选择页

启动后先进入“选择要打开的战役”：

- **推荐 · 内置规则**：创建包含 SF6 默认规则、默认角色卡、物品、敌人图鉴、地图和剧情资料的默认战役。
- **自由创建**：创建不带默认战役专属内容的空白战役。
- **继续**：打开已有战役。
- **恢复最近备份**：把该战役恢复到最近的本机恢复点；当前版本会先进入自动保存历史。
- **删除**：删除战役及其本地恢复点，操作前会再次确认。

默认战役专属的资料库、SF6 角色卡编辑器、默认敌人图鉴和默认物品不会自动出现在空白战役中。

### 1.3 DM 掌控端与玩家展示端

右上角“眼睛”按钮或“系统设置 → 页面运行角色”可以切换页面角色：

- **DM 掌控端**：可以修改战役、角色、地图、视野、物品和存档。
- **玩家展示端（只读）**：隐藏 DM 私密信息与编辑工具，不会把操作写回战役。

玩家展示端适合局域网设备直接查看；Discord、电视或投影串流优先使用独立的“直播展示窗口”。

## 2. 主页面布局

### 2.1 顶栏

顶栏从左到右显示 DMForge 标志、当前战役与章节、同步状态、主题和窗口级控制：

- **同步状态**：点击开启或关闭局域网同步；发生冲突时会打开设置处理。
- **主题切换**：切换界面主题。Logo 会按背景自动使用清晰的对比色，同时保留原有配色风格。
- **文件夹按钮**：保存并返回战役选择页。
- **直播按钮**：打开直播展示控制面板。
- **玩家视图按钮**：在 DM 掌控端和只读玩家展示端之间切换。
- **左右侧栏按钮**：折叠或展开角色列表、右侧工具栏。
- **设置按钮**：打开战役、同步、存档和直播设置。

### 2.2 左侧角色栏

左侧用于角色与 NPC 的快速管理：

- 创建玩家角色、NPC 或怪物。
- 按分组整理角色；分组可新建、更名、改色和删除。
- 查看 HP、临时 HP、AC、先攻、等级、资源和状态。
- 对选中角色进行短休或长休。
- 把角色拖入地图。拖动预览按棋子实际体型显示，不再显示整张角色卡。
- 单击角色卡时，完整资料会在右侧“角色”页显示；左侧不会展开成超长卡片。

### 2.3 中央工作区

主工作区包含以下页签：

- **战术地图**：地图、棋子、战斗、视野、绘图和地形编辑。
- **过场**：图片或循环视频场景、环境特效和转场。
- **物品**：世界物品池、角色背包、装备、消耗品和物品流转。
- **导入**：玩家角色卡、Excel 工作簿和外部规则资料。
- **图鉴**：默认战役中的敌人模板管理与生成。
- **资料库**：默认战役中的结构化规则资料。

“图鉴”和“资料库”仅在支持它们的默认战役内出现。

### 2.4 右侧工具栏

右侧一次显示一个面板：

- **角色**：显示当前选中角色的完整资料。点击左侧角色卡、地图棋子或战斗顺序角色会自动切到这里。
- **掷骰**：组合多个不同面数骰子后统一投掷。
- **日志**：查看战役、战斗、移动、物品和系统事件；可清空全部历史。
- **笔记**：建立、修改和删除 DM 笔记。

### 2.5 底部状态栏

底栏显示当前轮次、行动者、地图尺寸和网格比例、当前工作区、存档大小以及 LAN 状态。存档接近 10MB 上限时，应优先清理过大的图片、视频或冗余导入资料并导出备份。

## 3. 角色卡与角色管理

### 3.1 创建角色

点击左侧“新建战役角色 / 怪物”。默认战役会打开 SF6 原生角色卡编辑器；其他战役使用通用角色编辑器。

SF6 角色卡可记录或自动计算：

- 角色姓名、玩家姓名、角色类型、职业、子职业和等级。
- 国籍/背景、性别、MBTI 性格和角色简介。
- 角色头像与角色肖像。头像上传后可裁剪、放大和缩小；头像用于地图棋子和缩略卡，肖像用于完整资料。
- 六围属性、调整值、熟练加值、豁免和技能总值。
- AC、先攻、速度、最大/当前/临时 HP、生命骰、被动察觉和死亡豁免。
- 斗气槽、动作资源、攻击与施法、专长、职业特性和背包文字。

规则要点：

- 子职业在 **3 级**解锁。
- 技能熟练允许 **2 项出身默认熟练 + 3 项自选熟练**，合计最多 5 项。
- 专长槽按等级开放：3 级槽可选 3 级专长；5 级槽可选 3/5 级专长；8 级槽可选 3/5/8 级专长。
- AC 是可手动修改的数字。
- 每项攻击/技能可分别填写攻击加值、伤害骰数量、骰面、固定值、伤害类型和同一行的效果备注。

### 3.2 通用角色数据与资源

通用编辑器可设置角色类型、职业、子职业、等级、生命骰、HP、AC、先攻、速度、核心属性和自定义资源槽。资源槽可以设置名称、上限和恢复周期。

角色资料中的快捷控制可以：

- 以 1 或 5 点为单位调整 HP。
- 消耗或恢复资源槽。
- 添加有持续回合数的状态或永久状态。
- 升级并按生命骰提高最大生命值。
- 快速复制、详细编辑、移出地图或彻底删除。

“移出地图”只移除棋子，通常保留角色卡。例外：战斗中 NPC/敌人 HP 已归零时，手动移出地图会视为死亡清理，同时从角色列表和战斗顺序删除。

### 3.3 体型、占格和图片

角色体型支持从超微型到大型体型，包括 **0.25 格超微型**。棋子位置、拖动预览和路线计算都以图形中心为基准：

- 单格角色从当前格中心移动到目标格中心。
- 多格角色以整个占地范围的中心计算路径，并检查完整身位是否能通过。
- 更换头像不会改变角色数值或地图位置。

### 3.4 负重、装备与消耗品

角色负重上限由耐力相关数值计算。界面显示当前重量/上限及 **80% 预警线**：

- 达到 80% 后进入负重预警。
- 超出上限后会产生相应惩罚，并影响有效移动速度。
- 背包中的装备与消耗品分区显示，名称使用不同色彩帮助识别。

手电筒不是无条件能力。只有角色背包中存在数量大于 0 的“手电筒”物品时，地图角色控制区的“开启手电筒”才可用。

## 4. 战术地图基础操作

### 4.1 地图选择与配置

地图上方可选择当前地图，并显示宽×高及 `1ft` 网格规则。

- **新建地图**：创建空白地图。
- **地图配置**：修改名称、宽高、单格像素、背景图片 URL、背景缩放和偏移、室内视野上限，并控制玩家视野开关。
- **删除地图**：永久删除当前地图及相关地形数据，不可撤销。

使用背景图时，应让图片上的房间、走廊与应用网格重合。先调整比例，再调整 X/Y 偏移；最后用墙、门和家具边缘检查对齐。

### 4.2 平移、缩放与棋子

- 在普通地图状态下拖拽空白处可平移地图。
- 使用缩放按钮调整地图大小，使用复位/适配按钮快速回到可用视角。
- 从左侧把角色拖入地图；预览会显示实际占格大小。
- 单击地图棋子会选择角色并在右侧打开资料，不会改变战斗回合。
- 拖动角色时会显示预计路径、距离、是否受阻和剩余移动力。
- 路径规划阶段不会提前解锁目的地视野；棋子真正到达后才更新视野和迷雾记忆。

### 4.3 地图悬浮信息

鼠标在地图构件上短暂停留，会出现一个说明框，显示构件名称、当前状态、移动规则、视线规则、掩体以及已公开的陷阱效果。界面只保留一套悬浮提示，避免浏览器标题和自定义提示同时出现。

秘密构件在尚未被发现时不会向玩家端暴露。DM 端仍可识别和编辑。

## 5. 战斗与移动

### 5.1 发起战斗

点击“发起战斗”，勾选参战角色，然后点击“一键掷先攻并开战”。系统会：

1. 为所有参战者投掷 `1d20 + 先攻修正`。
2. 生成行动顺序并进入第 1 轮。
3. 分开显示行动顺序、当前角色状态和可操控资源，避免全部挤在一行。
4. 将行动权交给先攻最高的角色。

点击行动顺序中的角色只会选中并展示资料，不会跳过或切换回合。

### 5.2 当前行动区

当前角色区显示：

- HP、AC 和本回合剩余移动力。
- 状态效果及其剩余回合。
- 动作、附赠动作、法术或其他自定义资源槽。
- “重置该回合”和“结束回合”。

“结束回合”会把行动权交给下一位角色，并在一轮结束后增加轮次；持续状态会按设定倒计时。

“重置该回合”会把当前角色送回本回合起点并恢复该回合移动力，适合纠正误拖。

### 5.3 移动限制与强制位移

战斗中默认只有当前行动角色可以正常移动，且会检查：

- 剩余移动力是否足够。
- 完整体型能否通过墙、家具和其他不可穿越区域。
- 困难地形的双倍移动消耗。
- 路线是否可绕过阻挡。
- 进入区域后是否触发陷阱、环境伤害或状态提示。

需要击退、传送或 DM 修正位置时，开启“强制位移”，或拖动时临时按住 `Shift`。强制位移不消耗本回合移动力，但仍会记录日志。

战斗中非隐身参战单位会作为战斗已知目标保持可见提示；这不等于正常视线，也不会自动揭示其周围地形。

### 5.4 退出战斗

点击“退出战斗”并确认后，清除先攻队列并回到自由探索。角色卡、棋子位置、HP、状态和资源不会因为退出战斗自动重置。

## 6. DM 本地视野预览

地图工具栏的“视野”只改变 **当前 DM 页面**，不会影响玩家端和直播端：

- **全亮**：DM 查看完整地图，适合编辑与检查。
- **全暗**：DM 本地完全遮黑，适合验证黑屏或开场效果。
- **玩家视角**：DM 本地模拟玩家当前可见范围和探索记忆。

这三个选项是检查工具，不是公开画面的控制器。要改变玩家和直播看到的内容，使用“玩家视野”。

## 7. 玩家端与直播端视野控制

### 7.1 同步视野模式

点击“玩家视野”进入控制模式。此处的修改会同时影响玩家展示端与直播展示端：

- **玩家视角**：按玩家角色位置、光照、门墙遮挡和探索记忆显示。
- **全亮**：临时让玩家和直播看到整张地图。
- **全暗**：临时遮黑整张地图；DM 仍可用选区强制显示局部。

进入视野控制时默认选择“漫游”，因此仍可拖拽地图。只有切换到单格、矩形、圆形或锥形后，鼠标拖拽才用于画选区。

### 7.2 视野选区形状

- **漫游**：拖拽地图，不编辑视野。
- **单格**：点击一个地格。
- **矩形**：从一个角拖到另一个角。
- **圆形**：从圆心向外拖出半径。
- **锥形**：从起点向目标方向拖动；可选择 30°、45°、60°、90° 或 120°角度。

完成选区后可执行：

- **显示选区**：强制玩家和直播看到范围内地形。
- **遮蔽选区**：强制隐藏范围，并移除该范围的探索记忆。
- **恢复自动**：删除选区内的手动覆盖，让角色视线、光照和遮挡重新接管。
- **清除覆盖**：清除当前地图所有手动显示/遮蔽覆盖，恢复整体自动判定。

“显示选区”适合视野计算异常时，给出一个房间的地形信息。它不是全图揭秘，也不会让范围外角色、秘密物品或隐藏单位永久公开。

### 7.3 自然视野、光照与遮挡

默认玩家没有黑暗视觉。可见范围由角色位置、地图室内视野上限、光源和遮挡共同决定：

- 同一室内房间通常能在较短移动后探索大部分地形。
- 完整墙、关闭/锁定的门、柱子和高柜等会阻挡视线。
- 窗户、透明冷冻仓和透明样本罐允许视线或光线穿过，但可能阻挡移动与攻击。
- 半高墙、桌子和操作台按高度部分遮挡，并提供不同等级掩体。
- 开门后才会按新状态计算穿透视野。
- 玩家未在视野内看见门发生变化时，记忆中的门仍保持最后一次看见的状态。例如：玩家看见一扇关闭的门，之后门在视野外被打开，记忆画面仍显示关闭，直到再次看到它。

背包中有手电筒的角色可在角色地图控制区开启 60°锥形照明；关闭或失去物品后不能继续使用。

### 7.4 迷雾记忆

迷雾记忆把“当前看得见”和“以前探索过”分开：

- 当前可见区域显示实时地形、角色与物品。
- 已探索但当前被遮挡的区域保留地形记忆，例如墙壁、柱子和最后看见的门状态。
- 记忆区不会持续更新视野外新出现的角色、物品或构件状态。

控制按钮：

- **暂停记忆**：停止显示和追加探索记忆；角色当前真正看见的范围仍会显示。现有“起点”和“当前”档案不会被删除。
- **恢复当前（格数）**：重新启用暂停前累计的当前记忆，并继续实时记录之后探索的内容。
- **恢复起点（格数）**：回到记忆记录开始时的探索状态，然后继续实时记录。
- **设当前为起点**：把当前探索结果同时保存为新的“起点”和“当前”档案。适合进入新章节、清场或正式开局前建立基准。

推荐做法：开局摆好角色和初始房间后，先确认玩家视角正确，再点“设当前为起点”。这样误操作时可以恢复起点，而不必清空整张地图。

## 8. 地图标注与基础绘图

点击“地图标注”进入绘图模式。标注会同步到直播端，但只作为视觉层，不影响移动、地形或视野计算。

工具包括：

- **自由画笔**：在地图上绘制路线、范围、箭头或临时记号。
- **橡皮擦**：擦除局部笔画。
- **颜色**：选择画笔颜色。
- **粗细**：调整线条宽度。
- **撤回**：撤销上一次绘制、擦除或清空。
- **一键清除**：清除当前地图全部标注；清除后可以立即撤回。

地图标注、玩家视野控制和地形编辑互斥。切换模式时，应用会退出另外两种编辑状态，以减少误触。

## 9. 地形编辑器与地图组件

### 9.1 进入和退出

点击“快速编辑地图”进入地形编辑器；完成后点击“保存并退出编辑”。编辑面板集中在侧栏，主地图只保留当前必要工具。

### 9.2 编辑工具

- **地图漫游**：拖动地图，不移动构件。
- **移动构件**：只有启用此工具时，才可拖动组件或控制点改变位置和大小。这能避免平移地图时误改家具。
- **阻挡绘制/橡皮擦**：绘制或删除阻挡格。
- **框选区域**：拖出范围后，可移动或清除其中的阻挡格，也可“揭示框内地形”。
- **新建矩形地形 / 新建圆形地形**：建立自定义区域。
- **撤销**：撤销最近一步地形或阻挡操作。

选中墙体或物品后，地图上的对应组件会高亮，右侧只显示该对象的详细编辑项。

### 9.3 内置构件

构件库包括基础构件和战役常用素材，例如：墙、门、窗、柱子、半高墙、桌子、操作台、冷冻仓、主控制台、维护台、货架、储物柜、货箱、椅子、沙发、床、洗手台、卫生设施、摄像头、警报灯、扫描区、气体喷口、实验工作站、样本罐、服务器机柜、医疗推车、售货机、盆栽、长椅、发电机和便携路障。

选择构件类型后，可新增并调整名称、位置、尺寸、形状、朝向和外观状态。地图中只保留适量家具，不应占满玩家移动和战斗空间。

### 9.4 门与构件状态

门直接显示当前状态，不显示多余的“点击开启/关闭”提示。门状态包括：关闭、开启、半开、锁定和破坏。

- 开启或破坏的门允许按当前规则通行和观察。
- 关闭或锁定的门阻挡移动和视线。
- 半开门可设置门缝视角。
- 构件可设置为可破坏，并记录当前/最大耐久；可快捷 `耐久 -5`、破坏或修复。
- 带多状态素材的家具还可切换正常、警报、离线、占用、空置、损坏等外观状态。

### 9.5 移动、视野与掩体规则

每个地形或构件可独立设置：

- **地形穿越**：可直接穿越、不可穿越、双倍移动力、需要攀爬能力。
- **视野穿越**：完全允许视线、按高度部分遮挡、阻挡视线、单向阻挡视线。
- **掩体等级**：无、半掩体、四分之三掩体、全掩体。
- **高度**：离地高度和构件高度。
- **附加穿透**：光照是否可穿越、远程攻击是否可穿越。

使用“单向阻挡视线”时还可填写阻挡方向；使用部分遮挡时，离地高度和构件高度会参与判断。

### 9.6 灾害与陷阱

灾害级可设为“无（仅地形标记）”、烈火/熔岩、剧毒/酸性、冰霜/深水、碎石/困难地形或法术/诅咒，并可自定义颜色。

所有可触发陷阱应填写：触发条件、判定方式、触发效果、持续时间和解除方式。角色进入范围时，系统会在日志和地图提示中标注需要结算的效果。

秘密陷阱或构件可保持“玩家不可见”，发现后再切换“玩家已发现此秘密构件”。“揭示框内地形”只揭示地形轮廓，框内角色和物品仍受当前视野限制。

## 10. 物品池、背包与休整

### 10.1 世界未获得物品池

“物品”页的世界池保存尚未分配给角色的物品。可以：

- 从模板快速添加，或创建自定义物品。
- 按分类筛选。
- 修改名称、分类、数量、重量、热量、AC 加值、武器伤害骰、固定伤害、伤害类型、其他数值、效果和使用说明。
- 把指定数量分发给角色。

默认战役的世界池消耗品视为可反复获取的世界模板；角色背包中的实际数量仍会在使用时扣减。

### 10.2 角色背包流转

角色背包可把物品转移给另一角色、消耗 1 个或彻底删除。装备和消耗品分区、分色显示；物品重量会即时计入负重。

### 10.3 短休与长休

在左侧选择角色后使用短休/长休：

- **短休**：恢复 50% 最大 HP、3 格斗气，以及短休/回合恢复型资源。
- **长休**：恢复全部 HP 和全部资源，清除特殊负面状态并复原移动力。
- 长休需要平均每名玩家角色 **1500 kcal**；从已选择玩家角色的食物背包共享扣除。食物不足时不能确认长休。

## 11. 敌人图鉴

默认战役的“图鉴”按普通战斗人员、杂兵头领和 Boss 分类保存敌人模板。

- 单击模板可查看和编辑。
- “新增模板”创建自定义敌人。
- “导入 JSON”批量加入图鉴。
- 从图鉴添加非 Boss 敌人时，会从中文、英文、日文、韩文拉丁拼写和法文名字库随机分配姓名，并在括号中标注身份。
- 列表与战斗顺序只显示英文或法文姓名的 first/last 其中一部分；打开完整资料才显示全名。
- 从图鉴加入角色列表后，可继续拖到地图，或由图鉴入口直接放置到当前地图。

敌人模板可以记录职业、子职业、等级、HP、AC、先攻、速度、属性、豁免、资源槽、技能伤害、专长和携带物品。携带物品使用与世界物品池一致的分类、重量、AC 和伤害字段。

## 12. 过场与直播展示

### 12.1 过场页面

“过场”页可以建立开始、准备、转场、收尾和结局等场景：

- 上传图片或小型视频，单文件上限 4.5MB。
- 设置场景名称、画面标题、副标题/旁白。
- 选择环境特效、入场转场和特效强度。
- 选择“铺满画面”或“完整显示”。
- 视频可循环、静音；场景可启用暗角电影遮罩。
- “推送到玩家端”切换到该过场；“玩家端返回地图”恢复战术地图。

### 12.2 直播展示窗口

点击右上角直播按钮，在设置面板中打开独立展示页。Discord 直播时只共享这个窗口/标签页，不共享 DM 主页面。

直播场景包括：

- 战斗直播。
- 战术地图。
- 队伍概览。
- 剧情画面。
- 暂停画面。

可控制直播地图、镜头模式、字号、字幕、剧情标题、暂停文字、公开角色、是否显示玩家可见阻挡格和是否隐藏鼠标。

镜头可以跟随当前行动角色、跟随 DM 地图镜头，或由展示页独立拖动缩放。战斗和地图场景会同步棋子、路线预览、移动距离、移动力和玩家视野。

### 12.3 DM 左下直播导播

角色列表下方的迷你导播用于现场快速控制：

- 一键切换直播场景。
- 暂停/继续。
- 指定直播地图或选择过场。
- 打开、定位、刷新、重新检测和请求全屏。

如果直播页被手动关闭，点击“刷新/重新检测”：

- 未检测到页面时，按钮会恢复为“打开直播窗口”。
- 页面仍打开时，会重新载入并刷新连接状态。

浏览器阻止弹窗时，使用“在新标签页打开”。展示端支持折叠左右侧栏，方便获得更大的地图空间。

### 12.4 直播端公开信息规则

直播端可点击地图角色直接切换左侧资料，不会跳过战斗回合：

- 玩家角色：显示完整公开角色资料、数值、技能名称、专长、装备和消耗品。
- 敌人/NPC：只显示名字、职业等有限公开信息。
- 右侧显示简短行动历史和掷骰历史，战斗外也可查看。
- 不会公开 DM 笔记、秘密地形、隐藏角色、私有日志、同步令牌或完整敌人资料。

## 13. 掷骰、日志与笔记

### 13.1 掷骰

点击不同多面体骰子把它们加入待掷骰池；每次点击增加 1 个。点击下方待掷项目可减少数量。可以附加 `+4` 等公式或固定值，最后点击“掷骰”一次结算全部骰子。

结果会显示公式、每颗骰子和最终值，并进入本次会话的掷骰历史及战役日志。

### 13.2 日志

日志自动记录关键操作，如开战、先攻、回合、移动、状态、物品、导入、备份和视野控制。公开日志可以进入直播历史；私有系统/DM 日志不会公开。

“清空”会永久清除战役日志且不可撤销，清理前建议先做手动备份。

### 13.3 笔记和浮动规则窗

“笔记”页用于日常 DM 记录。导入的规则资料还可以作为浮动窗覆盖在地图上；浮动窗可移动、调整大小、隐藏或删除。

## 14. 玩家角色卡和规则导入

### 14.1 独立玩家角色卡

“导入”页可以：

- 打开独立玩家角色卡页面。
- 下载可直接发送给玩家的离线单文件 HTML。
- 下载 Excel 角色卡模板。
- 导入玩家从独立页面导出的 DMForge JSON。

独立玩家卡不与 DM 页面实时联动。玩家填写、保存并把 JSON 发给 DM 后，DM 再导入。

### 14.2 导入或更新玩家卡

支持 DMForge JSON 及 `.xlsx`、`.xls`、`.xlsm`、`.xlsb`。一次可以选择多个文件；每个文件会建立关联角色。

已导入角色卡旁的刷新按钮可重新选择更新文件。更新会覆盖角色卡字段，但保留地图位置、当前战斗状态、状态效果和当前资源。删除导入卡时，关联角色会保留，只解除自动关联。

只导入可信 Excel 文件。复杂宏、第三方公式链或损坏文件可能无法解析；可先在 Excel/WPS 另存为标准 `.xlsx`。

### 14.3 外部规则资料

支持导入 TXT、MD、JSON 纯文本或 Excel 规则表。可搜索、调字号、编辑正文、复制全文或把资料投射为地图浮动窗。

默认战役的结构化“资料库”与这里的外部规则导入是两套用途：前者是内置规则索引，后者用于临时增加战役参考材料。

## 15. 默认战役规则资料库

“资料库”支持搜索规则、状态、职业或专长，并按类别折叠：

- 战斗方式的子规则各自作为可展开子栏目。
- 职业与子职业按职业折叠；职业标题只显示职业名，职业通用特性与子职业内容在内部排版。
- 专长按等级分组，一个等级栏目内列出该等级全部专长。
- 人物状态集中展示状态规则。
- 其他规则按资源、角色创建、角色成长、世界设定等分类整理。
- 规则目录位于最后，完整 PDF 链接位于目录最醒目位置。

“招式创建”位于“角色创建”分类下。资料库是查阅工具，不会直接修改角色卡或战斗数值。

## 16. 存档、备份与恢复

### 16.1 自动保存

战役修改会自动保存到本机 IndexedDB；每次保存保留上一版本。独立 Node 服务可同时把状态写入 `campaign_state.json`，并维护近期、每小时和每日滚动备份。

不要在页面刚显示“正在保存”时强制结束进程。等待顶栏/设置中的状态变为“已保存”再关闭最稳妥。

### 16.2 手动备份

打开“系统设置 → 战役物理存档数据管理”：

- **创建手动备份**：立即建立本机恢复点；同步可用时同时建立服务器备份。
- **导出战役**：下载完整 JSON；可以输入密码，以 AES-256-GCM 加密。
- **导入战役**：从 JSON 恢复。导入前会自动建立恢复点。
- **本机恢复点**：查看并回滚本机历史。
- **服务器备份**：刷新列表并回滚服务器保存的版本。
- **恢复出厂设置**：按当前战役模板重建；需要两次确认，重置前会先建立恢复点。

导出文件包括战役数据、地图、角色、物品、日志、规则资料和导入的玩家卡。建议每章结束、重大地图编辑前和大量导入前各做一次手动备份，并把加密导出复制到另一块磁盘。

### 16.3 同步冲突

本机与服务器都在同一旧版本上继续修改时，会出现同步冲突，应用不会静默覆盖。设置面板提供：

- **使用服务器版本**：丢弃本机未同步修改。
- **使用本机版本**：用本机内容覆盖服务器。
- **先导出本机版本**：先保留 JSON，再决定采用哪一方。

不确定时先导出本机版本，再查看双方时间和内容。

### 16.4 安全提醒

- 战役 JSON 上限为 10MB。
- 主持人写令牌不要发给玩家；玩家应使用只读链接或只读令牌。
- `campaign_state.json` 和服务器滚动备份是本机明文文件；离机传输使用带密码导出。
- 便携版升级前备份 `campaign_state.json`、`campaign_state_backup.json`、令牌文件和 `backups/`。
- 不要把便携版放在无写入权限的目录。

## 17. 推荐的现场操作流程

1. 从战役选择页打开正确战役，确认右下角保存与 LAN 状态。
2. 做一次手动备份。
3. 选择地图，切到 DM“全亮”检查墙、门、背景、出生点和陷阱。
4. 放置玩家棋子，确认头像、体型、背包手电筒和初始资源。
5. 进入“玩家视野”，用“玩家视角”检查初始房间；必要时用单格、矩形、圆形或锥形“显示选区”。
6. 点击“设当前为起点”，建立本场迷雾恢复基准。
7. 打开直播窗口，选择地图/战斗场景，点击刷新确认连接和镜头。
8. 开始探索；路径预览只用于估算，到达后才更新视野。
9. 遭遇战时发起战斗、勾选成员并统一投先攻。
10. 每次转场或章节结束后，再做手动备份和加密导出。

## 18. 常见问题

### 玩家/直播看到的视野不对

确认你调整的是“玩家视野”，而不是 DM 顶栏的本地“视野”预览。先切回“玩家视角”，再检查角色位置、地图是否启用玩家视野、门状态、光源和室内视野上限。局部错误可框选“显示选区”；之后可“恢复自动”。

### 进入视野控制后不能拖地图

把视野选区切回“漫游”。单格、矩形、圆形和锥形会占用鼠标来创建选区。

### 规划路线时目的地提前亮起

当前设计只在棋子完成移动后更新自然视野。若预览阶段仍提前显示，先取消本次拖动，再检查该区域是否存在“强制显示”覆盖，并用“恢复自动”移除。

### 迷雾记忆消失或想回到开局

点击“恢复当前”找回暂停前累计状态；需要回到正式开局基准时点击“恢复起点”。二者都会继续记录后续探索。只有“遮蔽选区”会明确删除该区域的探索记忆。

### 直播端已经关闭，但 DM 仍显示打开

在左下迷你导播点“刷新/重新检测”。未找到展示页后会恢复“打开直播窗口”。

### 直播画面空白或地图不跟随

先刷新直播端，再确认直播场景不是“暂停画面”或“剧情画面”，直播地图是否设为“跟随 DM 当前地图”，镜头模式是否选对。需要完全由 DM 控制时选择跟随 DM 镜头。

### 地图拖动时家具被误移

退出“移动构件”并切回“地图漫游”。构件只有在专用移动模式下才应响应拖动。

### 角色不能开启手电筒

检查该角色背包是否有数量大于 0 的手电筒。世界物品池里有手电筒不等于角色已经持有，需先分发到该角色。

### 长休按钮无法确认

检查已选择玩家角色背包中的食物总热量。长休按每名玩家角色 1500 kcal 计算并共享扣除。

### 修改没有在另一设备出现

查看右上同步状态。显示“自动单机使用”时，本地修改已保存但尚未同步；连接恢复后会重试。出现“同步冲突待处理”时必须在设置中选择保留版本。
