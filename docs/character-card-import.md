# 角色卡导入能力

## 当前已经支持

- 支持 `.xlsx`、`.xls`、`.xlsm` 和 `.xlsb`，单文件最大 2 MB、最多 50 个工作表。
- Excel 在 Web Worker 隔离线程中解析，并限制为最多 50,000 个有效单元格、501 行和 101 列，避免异常工作簿拖死界面。
- 支持一次选择多份角色卡；每个工作簿独立创建一名关联角色。
- 自动识别中英文常见字段：角色名、职业、等级、当前/最大生命值、护甲等级、移动速度、先攻、生命骰和六项核心属性。
- 无法识别姓名时使用文件名；其他字段使用安全默认值，并在卡片上显示识别数量和提示数量。
- 保留原工作簿查看能力，包括多工作表、合并单元格、行高、列宽、公式文本和关键字检索。
- 每张角色卡都有独立的“重新导入”入口。更新时同步角色卡字段，但保留地图位置、所属地图、资源槽、状态和已有自定义特质。
- 删除工作簿时保留角色，并解除其自动同步关联，避免误删战役数据。
- 角色卡和关联信息会随战役存档、本地备份、手动导出及局域网同步一起保存。

## 自动识别原则

自动导入采用标签与邻近单元格识别，不依赖某一个固定模板。字段值可以位于标签右侧一至三格、下方一至两格，或写成 `HP: 20/30` 这样的同行形式。系统只写入已经识别的角色卡字段；重新导入不会覆盖战斗过程中的位置、资源与状态。

## 当前限制

- 浏览器安全模型不允许网页在未授权的情况下持续监视本地 Excel 文件，因此“自动更新”仍需要用户点击该卡片的更新按钮并重新选择文件。
- 不执行 Excel 宏，也不会运行或重新计算第三方公式链；读取的是工作簿内已保存的结果和公式文本。
- 自定义、纯图形化或标签极度特殊的角色卡可能只能识别部分字段。卡片会显示提示，但目前没有可视化字段映射向导。
- 当前自动创建的是玩家角色（PC）。怪物批量模板和一张工作簿包含多名角色的拆分导入尚未开放。
- 法术位、职业资源、技能、豁免、装备和特质缺少跨模板一致标签，暂不自动覆盖，避免破坏用户已经维护的数据。

## 建议的后续扩展顺序

1. 增加导入预览与字段映射面板，让用户确认后再写入，并保存每种模板的映射规则。
2. 支持标准 D&D 5e、PF2e 等模板适配器，导入技能、豁免、法术位和职业资源。
3. 增加“一个工作簿含多名角色”的工作表拆分模式。
4. 桌面启动器升级为原生文件访问后，可通过用户授权的文件句柄提供真正的变更检测；浏览器模式继续使用手动重新选择。
5. 为导入记录增加字段级差异预览和单项回滚。
